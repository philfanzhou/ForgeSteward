## 变更与迁移

- 额度较低、接近限制的提示不构成能力缺失或终止条件；仍派发必需阶段，不缩减请求轮数或伪造准备结果。
- 阶段交接及远端状态核对完成后，使用运行时实际提供的接口释放本次编排已完成线程。没有关闭接口时记录限制并继续，不虚构工具或把中断当成一定释放。
- 实际创建或等待调用失败后先核对任务状态，避免不确定创建结果导致重复写入；正常等待超时仍沿用原 Agent。
- 每次故障最多三轮状态核对，只有前两轮可在核对后恢复并重试操作，第三轮仅作最终状态核对；确认未创建才重新创建，等待失败沿用原任务。仅在确认必需能力缺失或有限恢复仍无法继续时保存交接并结束，报告实际错误和恢复证据。
- 每阶段独立子 Agent、新 Agent 复审、完整技能加载、同仓库串行写入及合并门禁保持有效。

既有用户按[固定版本安装、升级与回退](../versioned-installation.md)更新原安装子集；完整编排仍需六项插件版本一致。不需要新增调用参数、调整额度或全局配置，也不自动修改用户安装。

## 验证与边界

本地执行 148 项单元测试，145 项通过、3 项跳过（DeepSeek 实际 Provider 未指定，以及两项 Windows junction 测试）。OpenCode `1.18.32` 和 ZCode CLI `0.16.9` 在隔离目录验证技能发现、完整正文和资源；六项 Claude Code `2.1.283` 插件 strict 校验通过。技能预算和引用、市场同步、技能 quick_validate、50 个相对文档链接目标及 `git diff --check` 均通过。

PR 的三个 OS 安装器检查、固定 OpenCode `1.18.30` 发现检查及合并提交的四项检查均须通过，实际 SHA、检查链接和结果在 Release 正文记录。

新增[编排场景](../work-cycle-scenarios.md)覆盖低额度提醒、阶段回收、首次失败恢复、无关闭接口、不确定创建、正常等待、等待错误及恢复耗尽。独立子 Agent 对六个模拟快照进行只读推演，发现并修正状态查询与操作重试的计数歧义。安装器既有逐字节资源测试覆盖新增恢复规则的独立打包。规则走查及有限模型场景评估不等于真实额度错误、线程释放和跨 Agent 完整工作周期的端到端认证；本次不宣称修复运行时内部线程计数或保证所有平台提供关闭接口。
