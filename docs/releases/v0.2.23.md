# v0.2.23

This file is release input for `v0.2.23`. Publication is complete only when both the matching remote annotated Tag and a non-draft GitHub Release exist.

This release simplified work-cycle installation reporting: show section seven only when an Agent can be installed/upgraded or the current session package is older. It also scoped Codex read-only plugin queries to the ForgeSteward marketplace, reducing waits from unrelated remote catalog queries. All six plugins moved together to `0.2.23`.

## Changes

- **Show only actionable installation updates** ([PR #115](https://github.com/philfanzhou/ForgeSteward/pull/115), [Issue #113](https://github.com/philfanzhou/ForgeSteward/issues/113)): section seven lists only Agents with missing, incomplete, or older installations, no longer listing current, unknown, or development-version states individually. Read the session package version from bundled `scripts/VERSION` and separately flag an older session. Omit section seven when checks/latest are unavailable or nothing qualifies. Retain the full check JSON and render the first six sections normally. Installation authorization, detection JSON, and installation actions remain unchanged.
- **Scope Codex checks to the selected marketplace** ([PR #116](https://github.com/philfanzhou/ForgeSteward/pull/116), [Issue #114](https://github.com/philfanzhou/ForgeSteward/issues/114)): read-only `codex plugin list --marketplace forge-steward --json` skips unrelated remote catalog fetches while still reading names/versions from the `installed` array. In local macOS CLI `0.157.1` comparisons, the unfiltered query took approximately 0.936 seconds and scoped queries 0.059 / 0.045 seconds, with identical results for six plugins. This is not a timing guarantee for all environments. The 20-second per-command and 60-second overall limits remain. Unsupported options, query errors, timeouts, or format changes become unknown status, without retrying, unfiltered fallback, or internal-cache reads.

## Upgrade steps

Skill names, invocation, and installation data formats remain unchanged; no data migration is required. Follow [README](../../README.md#supported-agents-and-installation) to update to `v0.2.23`. All six plugins must share a version for work-cycle.

Behavioral changes: the final report no longer always shows seven sections; without update information it shows the first six only. If the session uses an older package, a new session is still required after updating installation to load the new version. Scoped Codex queries were verified with CLI `0.157.1`. Unsupported older CLIs affect only that Agent's installation-state check, without interrupting repository work.
