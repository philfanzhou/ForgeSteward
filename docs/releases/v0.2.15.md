## 变更与迁移

- 共用 description 维护预算从 1,024 收紧到 500 个 UTF-16 单元，覆盖 DeepSeek Harness `0.2.0-rc.2` 默认发现列表的完整描述展示边界；不改变正文的字节或行数预算。
- prepare-work 描述由 707 缩短为 487 单元；保留用途、排除场景、单行 Issue 输出、存量优先和默认数量。详细业务规则继续由原正文与引用文件维护。
- AGENTS.md、README 与跨 Agent 兼容文档明确限制的单位、可配置性质和验证范围；预算脚本与既有三 OS CI 检查阻止新增或修改描述再次超限。

后续贡献者须把超长描述的细节移到正文或引用文件中，不能依赖客户端调大显示长度，也不能为特定技能豁免。现有用户无需为这次描述修复调整客户端配置；本版本新增 `scripts/deepseek.py` 的 list/install/update/status/uninstall，复用共享安装事务核心并保留 OpenCode 契约；安装维护与固定源码回退见 [DeepSeek 文档](../deepseek-installer.md)。不宣称完整 DeepSeek 工作周期已经交付。

## 验证与边界

新增描述 500/501 单元、emoji 与混合字符、CLI 拒绝及未来插件自动纳入的回归。实际执行本机 DeepSeek Harness 包内 formatter，核对默认长度、空白归一化及边界，并确认六项描述均完整展示。早前隔离提供方验证确认六项完整正文与资源路径，本次修改后的实际提供方复验同样通过。

加入安装适配后，本地 148 项单元测试运行完成，其中 142 项通过、6 项因客户端或平台条件跳过；预算检查、市场同步检查、prepare-work 的技能校验、文档链接和 `git diff --check` 通过。PR 及最终 main CI 仍须在交付和发布时核对。桌面 GUI、真实子 Agent 阶段执行、合并行为和模型压缩恢复尚未得到本轮认证；静态长度检查及无模型调用的 formatter 验证不能替代这些验收。

Issue #40 安装适配验证另覆盖项目/用户完整资源、路径矩阵、固定 commit 回退、普通失败/取消/回滚失败、两个进程锁及有限卸载退出码；实际 `0.2.0-rc.2` Provider 在 macOS 隔离根通过全部正文与 resourceBase、资源摘要、排名和实际卸载后重新发现。未提供显式运行时的 CI 明确跳过真实 Harness 测试；原生 Windows Harness 与模型工作周期仍未验证。三 OS 静态回归继续执行，OpenCode Linux discovery 继续固定 `1.18.30`。
