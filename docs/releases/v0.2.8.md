## 相对 v0.2.7 的变化

来自 [PR #26](https://github.com/philfanzhou/ForgeSteward/pull/26)。

### review-and-merge（合并后结项）

- 新增更新本地主线步骤：本地存在主线分支时，获取远端后在检出主线且没有未提交改动的工作区中执行 `git merge --ff-only <远端>/<主线>`（如 `origin/main`）；不在其他分支上执行。有未提交改动或不能快进时保留原状并报告，不重置或强制覆盖。
- `git branch -d` 拒绝删除不作为分支未合并的证据（squash 或 rebase 合并后常见）；以平台合并状态核对本地分支 head 与已合并 Change Request 的 head 一致后才强制删除，不一致时保留并报告。
- 移除 worktree 后执行 `git worktree prune` 清理残留记录。
- 原“合并后结项”第 3、4 步顺延为第 4、5 步。

### execute-work

- “不能顺手重构”的列举加入改名。
- 以文档交付的目标设计中，secret 扫描与格式、链接、现有 CI 通过一样不作为语义正确的证据。

## 迁移说明

- 无不兼容变化，不改安装 ID 或调用方式。
- review-and-merge 合并后会在满足条件时快进本地主线，并可能强制删除已确认合并的本轮本地分支；主线工作区有未提交改动或本地分支 head 与已合并 head 不一致时不会改动。

## 安装、升级与回退

以下命令仅在本版本发布确认后使用，适用于尚未配置同名市场的新环境。已有安装先按 [版本切换与清理指南](../versioned-installation.md) 记录所选子集、作用域和来源，卸载旧副本并替换市场 ref，再安装原子集；不要重复添加同名市场或直接修改缓存。指南中 `v0.2.1` / `find-work` 是历史示例，本版本必须同时换成 `v0.2.8` 和上表实际插件名。

Codex 新环境示例（其他插件按上表逐项安装）：

```bash
codex plugin marketplace add philfanzhou/ForgeSteward --ref v0.2.8
codex plugin add review-and-merge@forge-steward
codex plugin list
```

Claude Code 新环境示例：

```text
/plugin marketplace add philfanzhou/ForgeSteward@v0.2.8
/plugin install review-and-merge@forge-steward
```

OpenCode 使用独立快照，替换以下占位绝对路径；安装命令从要维护的目标仓库执行：

```bash
git clone --branch v0.2.8 https://github.com/philfanzhou/ForgeSteward.git /absolute/path/ForgeSteward-v0.2.8
git -C /absolute/path/ForgeSteward-v0.2.8 rev-parse HEAD
python3 /absolute/path/ForgeSteward-v0.2.8/scripts/opencode.py install --all --project .
python3 /absolute/path/ForgeSteward-v0.2.8/scripts/opencode.py status --all --project .
```

先核对 checkout SHA 与 Release 一致再安装；已有安装使用同快照安装器的 `update --all --project .`（或按记录指定子集和 `--user`），不是重复 `install`。本地定制触发保护时先备份、核对再决定，不强制覆盖。

ZCode 按 [固定版本与回退](../zcode.md#固定版本与回退) 将已核对的 `v0.2.8` 独立 checkout 根目录加入本地市场，选择插件子集并核对实际安装版本。切换前保存原来源、卸载旧插件并移除旧市场；不直接套用 Codex 的 `--ref` 或 Claude 的 `@tag` 输入。

从 `v0.2.7` 升级只需切换版本，无额外迁移；从 `v0.2.6` 或更早版本升级，先阅读 [v0.2.7 迁移说明](v0.2.7.md#迁移说明)，其中 check-workflow 的删除行为是不兼容变化；从 `v0.2.1` 或更早版本升级，先移除退役 `find-work`，改装 `prepare-work`。所有已选插件均核对为 `0.2.8`。回退按相同步骤选择仍保留的 `v0.2.7`；回退不撤销已产生的项目改动、合并或托管平台操作。
