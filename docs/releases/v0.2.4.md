## 安装、升级与回退

以下命令仅在本版本发布确认后使用，适用于尚未配置同名市场的新环境。已有安装先按 [版本切换与清理指南](../versioned-installation.md) 记录所选子集、作用域和来源，卸载旧副本并替换市场 ref，再安装原子集；不要重复添加同名市场或直接修改缓存。指南中 `v0.2.1` / `find-work` 是历史示例，本版本必须同时换成 `v0.2.4` 和上表实际插件名。

Codex 新环境示例（其他插件按上表逐项安装）：

```bash
codex plugin marketplace add philfanzhou/ForgeSteward --ref v0.2.4
codex plugin add check-workflow@forge-steward
codex plugin add prepare-work@forge-steward
codex plugin add execute-work@forge-steward
codex plugin list
```

Claude Code 新环境示例：

```text
/plugin marketplace add philfanzhou/ForgeSteward@v0.2.4
/plugin install check-workflow@forge-steward
/plugin install prepare-work@forge-steward
/plugin install execute-work@forge-steward
```

OpenCode 使用独立快照，替换以下占位绝对路径；安装命令从要维护的目标仓库执行：

```bash
git clone --branch v0.2.4 https://github.com/philfanzhou/ForgeSteward.git /absolute/path/ForgeSteward-v0.2.4
git -C /absolute/path/ForgeSteward-v0.2.4 rev-parse HEAD
python3 /absolute/path/ForgeSteward-v0.2.4/scripts/opencode.py install --all --project .
python3 /absolute/path/ForgeSteward-v0.2.4/scripts/opencode.py status --all --project .
```

先核对 checkout SHA 与 Release 一致再安装；已有安装使用同快照安装器的 `update --all --project .`（或按记录指定子集和 `--user`），不是重复 `install`。本地定制触发保护时先备份、核对再决定，不强制覆盖。

ZCode 按 [固定版本与回退](../zcode.md#固定版本与回退) 将已核对的 `v0.2.4` 独立 checkout 根目录加入本地市场，选择插件子集并核对实际安装版本。切换前保存原来源、卸载旧插件并移除旧市场；不直接套用 Codex 的 `--ref` 或 Claude 的 `@tag` 输入。手工导入副本、其他作用域和遗留缓存按 [卸载指引](../zcode.md#卸载与只保留目标版本) 逐项确认，不删除其他插件的共享内容。

从 `v0.2.3` 升级不改安装 ID 或调用方式；从 `v0.2.1` 或更早版本升级，先移除退役 `find-work`，改装 `prepare-work`，按需加装 `execute-work`，没有旧名 alias。OpenCode 可用新安装器 `uninstall find-work --project .` 清理旧托管项，再安装新名称。新会话选择准备技能可直接运行；执行技能必须附明确清单，例如 `$forge-steward-execute-work #123, #145`。具体调用见 [README](../../README.md#calling-the-skills)。

所有已选插件均核对为 `0.2.4`，不因某插件正文未变而保留旧包。只清理确认属于旧版本且不再使用的副本，保留本地定制和其他环境。回退按相同步骤选择仍保留的 `v0.2.3`，核对版本和实际内容；升级技能不自动迁移使用方仓库规则，回退也不撤销已产生的项目改动或托管平台操作。

发布前执行全量单元测试、统一版本/市场/资源和格式校验、相对链接检查、受影响包的隔离安装验证。PR 与最终 main 的三个 OS 安装器检查及固定 OpenCode 发现检查必须通过，实际结果记录在 PR / Release。

本次只发布 Git 快照和 GitHub 自动源码归档，不提供独立构建包；不修改本机真实安装或用户配置。
