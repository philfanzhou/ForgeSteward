## Changes

- `work-cycle` processes Change Requests already open at startup before the first Issue-preparation cycle. Even if `prepare-work` later returns `[]`, existing PRs still receive review, necessary repairs, eligible merges, and cleanup. Startup review does not count as a work cycle.
- On each invocation, `check-workflow` reads the repository's automatic post-merge source-branch deletion setting and reports enabled, disabled, or unconfirmed state with evidence. It does not change settings or create an empty PR because the setting is disabled.
- After merging, `review-and-merge` reads back the remote source branch. If the platform has not deleted it, automatic deletion and a further check occur only for a same-repository source branch whose head is unchanged, is unprotected, and is unused by another open Change Request. Local branches continue to be cleaned up safely based on merge status, head, workspace, and shared use. A disabled or unknown setting does not prevent per-branch safety checks. Preserve and report branches when confirmation or deletion fails.

## Migration

After upgrading from `v0.2.13`, explicitly invoking `work-cycle` may merge PRs already open at startup before preparing new Issues. Explicit `review-and-merge` invocation, or review dispatched by `work-cycle`, automatically deletes merged remote source branches in the same repository when safety conditions hold; it no longer merely prompts the user because automatic deletion is disabled. Explicitly identify branches to retain when invoking the Skill. Original acceptance criteria, required checks, approvals, branch protection, and platform permissions still apply. Repository settings are unchanged.

The six plugins remain independently installed, but a complete work cycle requires the five stage plugins at the same version and a runtime that can create and wait for subagents. To upgrade a marketplace or installed copy pinned to `v0.2.13`, switch to this version's Tag and preserve the original subset and scope using [fixed-version installation, upgrades, and rollback](../versioned-installation.md). Updating only the Agent application or refreshing the marketplace index does not update Skills.
