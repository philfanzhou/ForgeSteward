## Handoff records

Use the existing tracker, task, or repository-designated location for one current-state record. Write only within authorization; without a writable location, provide a complete transferable record in the output, not a new tracker. Fill actual values: cleanup baseline/mainline; full task/Change Request links, implementation repository/mainline; audit baseline, coverage, evidence locations; current head and individual acceptance evidence; feedback classification, review rounds, resolved feedback, accepted limits; blockers, next steps, and release conditions. Mark missing fields unknown/not applicable; never infer acceptance or reset rounds. Also record commits, push results, and re-review readiness. A push does not complete a task. Separate new work, rework, and remaining original cleanup scope; splitting/moving work is not delivery and unknown counts must not be guessed.
