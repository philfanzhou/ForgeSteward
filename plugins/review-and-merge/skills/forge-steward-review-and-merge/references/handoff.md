## Handoff records

Use the existing tracker, task, or repository-designated location for one current-state record. Write only within authorization; without a writable location, provide a complete transferable output record, not a new tracker. Record actual cleanup baseline/mainline; full task/Change Request links, implementation repository/mainline; audit baseline, coverage, evidence locations; current head and individual acceptance evidence; feedback classification, review rounds, resolved feedback, accepted limits; blockers, next steps, and release conditions. Mark missing fields unknown/not applicable; never infer acceptance or reset rounds. Record actual merges and task/parent closures. Count initial-task delivery/remainder, additions, rework, and parent closures separately. Splitting, moving, duplicate closure, or closing as unplanned is not feature delivery. Do not guess unknown counts.
